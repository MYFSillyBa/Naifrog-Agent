# 非游戏功能接入实现计划

Goal: 交付可配置聊天、动作情绪、陪伴、屏幕辅助及可预览撤销整理的奶蛙。

Architecture: Core 保存配置和领域数据；Chat 实现模型调用与记忆；Animation 实现素材和调度；Files 实现事务式整理；主窗口与分类设置页组合功能。

全局约束：.NET 9 Windows / WPF，不增加第三方代码运行依赖；配置与密钥分开保存，敏感数据用 DPAPI；任何真实文件移动/外部模型请求均以用户操作为入口；右键菜单保持设置/退出。此目录非 Git 仓库，不创建或提交仓库。

- [ ] 共享配置、加密保存与服务接口；准备参考动画包。

- [ ] 独立任务：动画清单、缓存、情绪调度及 WPF 微动作。
- [ ] 独立任务：分类预览、快捷方式/复制/移动事务、撤销与文件验证。
- [ ] 主窗口、聊天窗、屏幕预览、日常行为、全局快捷键与分类设置页集成。
