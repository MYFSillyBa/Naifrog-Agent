# Windows Setup 安装程序

目标：提供一个可直接下载的 Windows x64 安装 EXE，使用现有奶蛙图标，包含 .NET 运行时、全部动画和来源声明。

方案：Inno Setup 6，固定 AppId 便于后续覆盖升级；当前用户安装，无需管理员权限。提供简体中文向导、开始菜单入口、可选桌面快捷方式和标准卸载入口。配置保留在原来的用户数据目录。卸载仅删除安装文件及指向该安装目录的开机启动项，不删除聊天与凭据。
