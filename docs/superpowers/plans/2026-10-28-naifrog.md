Architecture: WPF Image 显示嵌入的透明 PNG，窗口管理显示位置，App 管理单实例和托盘。使用 C#、.NET 9、WPF，无第三方运行库。

- [x] 实现透明置顶窗口、单实例、托盘退出和嵌入素材。
- [x] 完成实际启动、窗口属性、空闲占用、单实例与退出检查。
