# 运行中补充引用与模型选择

用户要求：Agent 正在执行时可以发送消息，作为引用加入同一任务且不打断；工作台模型名称改为可选择，读取用户 API 返回的全部模型。

## 行为

- 运行中发送通过线程安全引用队列，下一次模型请求前按顺序纳入 user-role 的引用消息。不中止当前 HTTP、命令或工具批次，不放宽权限，不替换初始目标。
- 正在返回最终回复时，若已有接受的补充引用，继续处理；若任务已关闭接收窗口，输入不得丢失。停止时未纳入的引用保留，继续任务时按时间顺序纳入。
- 界面立即显示补充引用，区分待引用、已加入上下文；运行中发送按钮可用，输入内容成功提交后才清空。任务隔离，队列和引用状态进入加密记录；不伪称模型已经理解。
- 工作台模型名称使用可编辑/可选择下拉框和刷新入口；读取现有 API BaseURL 的兼容 GET /models，使用相同凭据快照，无内置 Key。保留手动输入，不因模型列表不支持阻止聊天。
- 设置页模型 ID 提供可编辑下拉框与获取列表。仅点击保存或用户在工作台确认选择后保存模型，输入刷新不会重置现有选择。列表可搜索/键入，保留服务返回 ID，不虚构支持能力。
- 活跃任务沿用启动时的模型快照；工作台选择器在当前任务运行时禁用，避免静默中断或混用端点/Key。服务变化或并发刷新时丢弃过时的列表，不用旧服务模型覆盖新配置。

## 追加界面与精简要求

文件改动显示文件数量、文件名和新增/删除行数。文件名可点选，打开带行号的原生差异视图，新增绿、删除红，支持复制。差异计算后台运行，普通代码使用 LCS；大段重写受计算预算约束，按替换展示并明确标记。统计范围是文件工具快照，终端改动另用 Git diff 查看。

用户确认精简范围：移除其他奶蛙互动、桌面整理和拖入接收；保留聊天、动作、专注、屏幕。移除运行逻辑和设置入口，旧整理源码不再编入应用，历史用户数据保留。

## 验证

真实异步 fixture 阻塞 HTTP 和命令授权时发送引用，确认不取消原工作、完整工具配对、FIFO、最终回复边界、取消后保留、多实例/多任务隔离、加密保存和压缩后保留。GET models 测试使用模拟 HTTP，核对端点、Key、全列表、重复/非法字段、拒绝重定向、取消和错误脱敏。WPF 和实际窗口检查运行中发送、引用状态与下拉选择。保持原生 WPF。
