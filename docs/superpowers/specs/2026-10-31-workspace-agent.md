# 奶蛙工程 Agent

用户要求：为桌宠加入截图列出的工程能力，使用用户自己的 API Key；保持独立设计、原生 WPF，不使用 Web UI。

## 交付范围

从设置页打开工程工作台，选择目录并描述任务。模型可列目录、搜索和读取文本、创建/覆盖/精确替换/删除文本文件、运行终端命令；由命令运行构建、测试及 Git。工具结果回传模型，循环至模型结束、用户取消、接口错误或达到轮数限制。支持新任务、继续对话、不同工作区并行任务。同目录任务不得并发。默认使用现有模型配置和 DPAPI Key，Agent 有独立提示词、轮数/上下文/命令超时设置。

## 边界

文件工具拒绝目录逃逸、链接/reparse、设备路径、ADS、二进制或过大文本；写入需当前内容哈希，防止覆盖用户同时修改。变更保存前后快照，提供逐文件预览与保守撤销；终端产生的改动由 Git diff 查看，不冒充可撤销快照。终端不是沙箱：明确展示命令与工作目录，默认每条询问，用户可为本任务授权连续执行，也可完全禁止。取消/超时终止子进程树并回传真实结果。API Key 不写入任务日志。工程文件及命令输出在任务请求中发送给用户选择的模型服务。

## 界面

原生 WPF 工作台，任务列表、任务输入、执行时间线、改动/命令输出。工作区通过系统目录选择器指定。启动任务时明确选择允许文件编辑和命令策略。右键菜单仍仅设置、退出。聊天界面增加工程入口。日志与文本快照在配置目录加密落盘，退出取消任务。

## 验证

临时目录文件工具测试：读写搜索、精确替换、哈希冲突、逃逸/链接阻断、撤销冲突；真实本地命令测试：退出码、输出、取消、超时与拒绝。模拟 HTTP 验证工具调用往返、多轮修复、接口失败、无工具支持、任务并发与取消。WPF 集成验证入口、配置、工作区选择后启动及实际模拟接口任务。构建发布并检查内嵌资源，不使用真实 Key 或用户项目作为测试对象。
