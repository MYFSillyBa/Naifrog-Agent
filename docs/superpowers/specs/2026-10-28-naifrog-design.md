# 奶蛙桌宠首版设计

用户目标：根据提供的三视图制作 Windows 桌宠，动作与角色互动留到后续。用户希望尽可能有 3D 效果，并允许效果不理想时回到最初的透明图片方案。

最终采用 C# / .NET 9 / WPF 和透明正面 PNG。立体感来自素材中的光影，并非可旋转的三维模型。真实网格方案试作后与参考图存在明显差距，因此按用户指示回到图片方案。

窗口透明、无边框、置顶、不在任务栏占位，默认在主屏工作区右下角。系统托盘提供退出入口；不加入角色动作、拖动或鼠标互动。显示为保留模式，不用动画计时器。应用负责单实例和托盘生命周期，窗口负责位置与图像显示。

提供源码、构建脚本、可执行程序和中文说明。验证包括 Release 编译、实际窗口透明/置顶属性、角色截图、单实例和退出清理以及空闲资源采样。目录不是 Git 仓库，不创建分支或提交。

原图名为 nnn.png，实际编码为 AVIF；原始文件保存为 assets/original-reference.avif，PNG 转码预览保存在 assets/reference.png。角色 PNG 由内置 imagegen 制作，生成提示词随项目保存。图像生成有细节差异，不称为逐像素抠图。
