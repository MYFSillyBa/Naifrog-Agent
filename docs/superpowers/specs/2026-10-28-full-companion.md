# 奶蛙非游戏功能接入设计

用户已授权接入可用的非游戏功能，并要求设置页分类清晰；追加明确要求聊天支持用户自行填写 API、模型及提示词。

沿用 C# / .NET 9 / WPF。功能分为：配置与数据、聊天与模型、资源与动作/情绪、桌面行为、文件整理。右键菜单保持设置/退出，设置页集中提供功能入口与配置。支持原始立绘和参考动作资源，保留来源声明。

配置页：概览、外观与动作、模型与聊天、情绪与性格、陪伴与专注、屏幕与隐私、文件与整理、数据与高级。API Base URL、Key、模型 ID、用户系统提示词均可修改，连接测试可用。密钥及对话使用当前 Windows 用户加密。外部请求、截图和文件操作均由用户主动配置/操作；本次验证用本机模拟模型，不发送真实私人数据。

动作层支持序列帧和定格微动作、入场退场、优先级、冷却、惯性、重复合并、占用阻塞、缺失素材兜底。桌面层支持拖动、缩放、位置保存、鼠标旁召唤、可选快捷键、散步、启动问候、晃动反馈、深夜困倦、专注计时和主动陪伴。聊天支持流式输出、取消、重试、有限加密记忆；独立情绪分类失败不阻断正文。屏幕功能提供范围选择、预览及明确启用后的附图，授权不跨进程启动恢复。

整理功能独立预览：本地规则分类、可选模型细化、可编辑分类、原位置引用、快捷方式、复制、移动、执行记录及撤销。所有写操作必须来自预览页明确点击；不覆盖已有文件，失败报告逐项展示。拖入接收默认复制、保留原文件。

不引入格斗、网络对战或其他游戏。没有原始素材支持的动作不冒称真实三维动画。按模块验证后发布更新并实际启动。
